# 🛍️ ShopEase — E-Commerce Frontend

A modern, responsive **E-Commerce Frontend Application** built with **React.js, Redux Toolkit, React Router, and Tailwind CSS**.

ShopEase provides a smooth shopping experience with product discovery, search, filtering, sorting, product details, and complete cart management.

---

## ✨ Features

### 🏠 Home & Products

* Attractive and responsive home page
* 20+ products
* Product categories and ratings
* Product search by name
* Category-based filtering
* Price sorting

### 📦 Product Details

* Detailed product information
* Product image gallery
* Product ratings and categories
* Add products directly to cart

### 🛒 Shopping Cart

* Add products to cart
* Increase / decrease product quantity
* Remove individual products
* Clear entire cart
* Automatic total price calculation
* Automatic total item calculation

### 📱 Responsive Design

* Fully responsive layout
* Optimized for desktop, tablet, and mobile
* Clean and modern user interface

### ⚡ State & Navigation

* Centralized state management using Redux Toolkit
* React Router for smooth page navigation
* Reusable React components
