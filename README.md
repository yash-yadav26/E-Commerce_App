ShopEase — E-Commerce Frontend

A modern, responsive E-Commerce Frontend Application built with React.js, Redux Toolkit, React Router, and Tailwind CSS.

✨ Features
🏠 Attractive responsive Home Page
🛍️ 20+ products with categories and ratings
🔎 Product search by name
🏷️ Category filtering
↕️ Price sorting
📦 Product details with image gallery
🛒 Add to Cart functionality
➕ Increase / decrease quantity
❌ Remove products from cart
🧹 Clear cart
💰 Automatic total price & item calculation
📱 Fully responsive for mobile, tablet & desktop
⚡ Redux Toolkit for centralized state management
🧭 React Router for page navigation
🛠️ Tech Stack
React.js
Vite
Redux Toolkit
React Redux
React Router DOM
Tailwind CSS
JavaScript
